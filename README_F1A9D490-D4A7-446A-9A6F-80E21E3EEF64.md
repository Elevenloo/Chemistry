## 🚀 上傳 GitHub（3 分鐘完成）

### 方法 A：只上傳檔案（當作品集）

1. 在 GitHub 新建 Repository（例如 `hkdse-chem`）。
2. 上傳 **`index.html` 一個檔案就夠了**（CSS 與 JS 已全部內嵌在裡面）。

> `assets/` 資料夾是原始碼副本（方便修改），**不上傳也不影響運作**。

3. 完成。

### 方法 B：用 GitHub Pages 免費線上開啟（推薦）

1. 新建 Repository，上傳 `index.html`。
2. 進入 **Settings → Pages**。
3. **Source** 選 `Deploy from a branch`；**Branch** 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等 1–2 分鐘，網址會是：

```
https://<你的帳號>.github.io/<repo 名稱>/
```

> 若 repo 名稱改成 `<帳號>.github.io`，網址會更短：`https://<帳號>.github.io/`

### 進階：用終端機上傳

```bash
cd hkdse-chem
git init
git add .
git commit -m "HKDSE 化學複習網"
git branch -M main
git remote add origin https://github.com/<帳號>/<repo>.git
git push -u origin main
```

## 🔧 單檔案結構說明

`index.html` 是**完全自包含**的單一檔案：

| 內容 | 位置 |
|---|---|
| 樣式 CSS | 內嵌在 `<head>` 的 `<style>` 區塊 |
| 12 個 JS 資料與邏輯檔 | 內嵌在 `<body>` 末尾的 `<script>` 區塊 |

因此**不會有任何檔案路徑問題**：單獨一個 index.html 放到任何地方、
用任何瀏覽器雙擊開啟、或上傳到 GitHub Pages，功能都完整。

若程式未載入（例如只取到部分內容），頁面會主動顯示「⚠️ 程式未載入完成」的檢查提示。

想改樣式：編輯 index.html 內 `<style>` 那段（或改 `assets/css/style.css` 後重新內嵌）。
想改內容：改 `assets/js/` 對應檔案後重新內嵌。

## 🆕 近期優化

### 1. 原子模型：電子繞核旋轉
點擊週期表任一元素後，原子模型的**電子會沿軌道繞原子核轉動**：
- 每一電子層是一個獨立旋轉群組，**內層快、外層慢**（5s、7.6s、10.2s…）
- 相鄰層**旋轉方向交替**（順／逆時針），視覺更立體
- 電子使用漸層發光、原子核帶光暈
- **點擊原子圖可暫停／繼續**旋轉（方便觀察電子層數）
- 支援 `prefers-reduced-motion`：系統開啟「減少動態效果」時自動靜止

### 2. 有機轉化圖：醇置中 + 連線標註轉化方式
參考 DSE 有機化學轉化關係圖重製：
- **醇放在正中央**（標示「★ 轉化樞紐」，框體加大），其餘官能團環繞
- 每條連線**直接標註試劑／條件與反應類型**，例如：
  - 醇 → 酯：`+ 羧酸 / 濃 H₂SO₄，Δ（可逆 ⇌）`
  - 酯 → 羧酸：`1. H⁺／加酸水解（可逆 ⇌）`、`2. OH⁻／加鹼水解（不可逆 →）`
  - 醇 → 烯烴：`濃 H₂SO₄，Δ / 或 Al₂O₃ 加熱`（消去）
- 箭頭顏色區分反應類型（氧化／還原／水解／酯化／取代／消去／加成／中和），附圖例
- 標籤有**自動避讓演算法**：不壓節點框、不互相重疊，必要時拉細虛線指引
- 新增二鹵烷、醯胺節點；底部附符號說明（[O]、[H]、Δ、X、R、⇌、→）

### 3. 目錄改成左上角抽屜
- 頂部左側一顆 **☰ 目錄按鈕**，按一下從左側滑出目錄欄
- 12 個功能全部列出，點選後**自動跳轉並關閉抽屜**
- 支援點遮罩關閉、右上角 ✕ 關閉、`Esc` 鍵關閉
- 手機／平板／電腦皆可用，滑動順暢

## 💧 溶解度表（新增）

陽離子 × 陰離子的溶解性對照表，判斷沉澱、寫離子方程式的必備工具。

### 表格
- **13 種陽離子** × **8 種陰離子** = 104 格
- 陽離子：Na⁺、K⁺、NH₄⁺、Mg²⁺、Ca²⁺、Ba²⁺、Ag⁺、Cu²⁺、Fe²⁺、Fe³⁺、Al³⁺、Pb²⁺、Zn²⁺
- 陰離子：NO₃⁻、Cl⁻、Br⁻、I⁻、SO₄²⁻、CO₃²⁻、OH⁻、S²⁻
- **四種代碼**（配色沿用常見教材）：
  - 🟢 **S** 可溶（綠底）
  - 🩷 **I** 不溶（粉底）
  - 🟡 **Sl** 微溶（黃底）
  - ⬜ **—** 不存在／在水中完全水解或氧化還原（灰底）

### 互動
- **點儲存格** → 彈窗顯示化學式、溶解性、顏色外觀、備註，並自動生成離子方程式（如 Ag⁺(aq) + Cl⁻(aq) → AgCl(s)）；可一鍵跳到化合物圖鑑搜尋該物質
- **點表頭**（陰離子）→ 高亮整欄，其餘淡化
- **點行首**（陽離子）→ 高亮整列
- 兩者可同時使用（高亮單一格）；提示列有「✕ 取消高亮」
- 搜尋框：輸入 AgCl、硫酸鋇、Ba²⁺、OH⁻ 等關鍵字，過濾列並標記命中格

### 附帶內容
- **溶解度規則速記** 6 條：全部可溶組、鹵化物、硫酸鹽、碳酸鹽、氫氧化物、硫化物
- **常考沉澱顏色** 22 種：附色塊與檢驗用途（AgCl 白、AgBr 奶黃、AgI 黃、BaSO₄ 白、Cu(OH)₂ 藍色膠狀、Fe(OH)₃ 紅棕、Fe(OH)₂ 綠、Al(OH)₃ 白色膠狀、CuS／PbS／FeS／Ag₂S 黑、ZnS 白…）

## 📕 錯題本（新增）

答錯的題目會**自動收錄**，也可以**手動加入任何一題**（不必真的答錯）。每一題都能單獨管理。

### 逐題管理
- **自動收錄**：練習時答錯即自動進錯題本
- **手動加入**：錯題本下方搜尋題庫，按「＋ 加入錯題本」即可
- **題目上切換**：答題時每題都有「☆ 加入錯題本 / ★ 已在錯題本（點擊移除）」按鈕，隨時切換
- **逐題刪除**：每條錯題右上角「✕」

### 批次管理
- 勾選框逐題勾選 → 「刪除所選」
- 「全選本頁」→ 一次清空當前篩選
- 「清空錯題本」（有二次確認）

### 其他
- 統計四格：錯題總數、涵蓋課題、最多錯的課題、已勾選
- 按課題篩選 chips
- 「重做這些錯題」：只練錯題本裡的題目（可混合卷庫與自測題庫來源）
- 「⬇ 下載錯題本」：匯出含題目、選項、答案與解析的 HTML，開檔列印即可存成 PDF
- 每條錯題顯示：所屬課題、題型、來源（哪一年卷 / 自測題庫第幾題）、正確答案、解析
- 紀錄存在瀏覽器 localStorage，重開保留
